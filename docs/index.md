# Documentation
Welcome to the documentation for Beluga.

Beluga is a general-purpose scraping engine that allows scraping jobs to be configured and managed through configuration
files and a REST API.

## Documentation

### Configuration
Learn how to configure the scraping engine and its available options.
- [Configuration](/docs/configuration/configuration.md)
- [Jobs](/docs/configuration/jobs.md)
- [Persistence](/docs/configuration/peristence.md)
- [Result storage](/docs/configuration/result_storage.md)
