# X-Scraper
This is an open-source scraping engine that is currently in development. Currently, I am working on 
version v1.0 which will be the initial released version after which it will be open sourced and free
for anyone to use. I started this project as a passion project, I like anything that has to do with
data processing or that deals with high throughput. 
<br>
<br>
My goal is to make a general purpose scraper as many companies design their own in house scrapers which
might be reusable but more often than not aren't. Therefore, I decided to build a scraping-engine that 
is configurable and will eventually offer a lot of flexibility. I want it to be able to be used both 
locally for data scientists or in a production environment as a microservice. I realize that this is a lot
of features to build alone. But I will try nonetheless, besides that it also is interesting to put on 
a resume, as this is not a standard resume product but a product that could have real world usage. 
<br>
<br>
